# Heritage International School Website

A responsive school website built with HTML, CSS, and JavaScript.

## Features

- Responsive Design
- Hero Section
- About Section
- Academics Overview
- Admissions Information
- Contact Details
- Smooth Scrolling Navigation

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm start
```

The website will open in your browser automatically.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Live Server
